# Brand

## Name

**Working name: Questlight.** It's configurable in `src/config/brand.ts`.

"Quest" carries the game side (a path, progress, a challenge). "Light" carries the learning side (the moment something clicks). The name is two everyday English words, so it's easy to say and spell in most languages. It isn't a variation on "quiz", "study" or "learn", and it works for a 12-year-old and an 18-year-old alike.

### Top five

1. **Questlight**: the only candidate that is meaningful, edtech-appropriate, and showed no direct clash in the search. It has a clear visual idea, a path with a light on it.
2. **Kairo**: short and invented, so it could be owned. However, an AI wellbeing app already uses it.
3. **Tessel**: mosaic pieces map well to topic mastery. The main existing user is a hardware platform, so the overlap is lower.
4. **Nimbo**: friendly and easy to say internationally, but it's generic, and similar "Nimbus" study apps exist.
5. **Elevo**: positive and simple, but it means less, and an HR-software brand already uses it.

**Before launch:** run UK IPO and EUIPO trademark searches in classes 9 and 41, check domains (.com, .co.uk, .app), and check social handles for the final choice.

## Identity

**Personality:** calm, clear, quietly competitive, and honest. It talks like a good older student, not a teacher and not a games console.

**The core idea:** a deep navy room where the learning material sits on bright paper. Questions, flashcards and explanations are always on paper surfaces, and everything else stays in the room. This keeps the interface calm and puts the student's attention on the content.

| Token | Hex | Use |
|---|---|---|
| Night | `#0D1322` | Page background |
| Deep / Slate | `#131A2C` / `#1B2338` | Panels, sidebar, inputs |
| Ink / Ink soft | `#E9ECF4` / `#A7AFC6` | Text on the room |
| Paper / Paper ink | `#F4F5F8` / `#151B2B` | Learning surfaces and their text |
| Beam | `#7B86FF` | The single accent: focus, progress, primary action |
| Correct / Incorrect | `#22A77A` / `#D94A5F` | Answer feedback only, always with an icon and words |

**Logo:** an open orbit (the quest) with a point of Beam-coloured light on it (the moment something clicks). The wordmark is lowercase *questlight* at tight tracking, sitting next to the mark.

**Typography:** one family, Schibsted Grotesk, a sturdy grotesk with some character. Weights are 400 for body text, 500 for interface labels and 600 for headings. Numbers use tabular figures wherever they change (XP, scores, timers).

**Icons:** Lucide at a 1.75 stroke, monochrome, in the colour of the text around them.

### Rules

- There is one accent colour. Cards are never given different colours.
- Green and red mean correct and incorrect, and nothing else. They always come with an icon and text.
- There's one signature motion: a beam of light crosses the paper when you get a question right. Every other animation responds to something the user did.
- Headings and labels are in sentence case, with no all-caps labels.
- Corner radius grows with surface size: 6px for chips, 10px for controls, 20px for large panels.
- Shadows appear only on paper surfaces and raised panels.
